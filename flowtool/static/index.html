SFDC Flow Tool

How do I get this?

No install - log in to the org in this browser, open DevTools (F12) → Network, click any request to /services/data/... (Setup and Lightning make these constantly), and copy the value after Bearer or OAuth in its Authorization request header - that is the session ID/access token. The instance URL is the address bar's origin. The same trick works on any request made by a browser extension that talks to the org, Salesforce Inspector Reloaded included - it reuses your login rather than issuing its own token, so there's nothing to copy from the extension itself.

Native to Salesforce - Setup → Visualforce Pages → edit or create one → add {!GETSESSIONID()} to the markup → open the page. Needs Visualforce access (System Administrator has it by default).

With the sf CLI installed and logged in: sf org display -o your-alias --verbose --json for instanceUrl, then sf org auth show-access-token -o your-alias for the token - recent CLI versions redact it from org display and require the separate command. No alias set as default yet? sf org list shows what you have, or sf org login web -a your-alias connects a new one.

None of these are stored anywhere - sent only with requests, same as OAuth.
