# Store assets: icons and screenshots

## Icons

| File | Size | Used for |
|---|---|---|
| `extension/icons/icon16.png` | 16x16 | Favicon on the extension's pages, toolbar fallback |
| `extension/icons/icon32.png` | 32x32 | Toolbar action (HiDPI) / Windows |
| `extension/icons/icon48.png` | 48x48 | `chrome://extensions` |
| `extension/icons/icon128.png` | 128x128 | Install dialog and Web Store listing (store icon: 128x128, artwork about 96x96 inside 16 px transparent padding) |

Placeholders (blue rounded square with the three-node mark) are generated by `python extension/tools/make_icons.py`. Replace them with final artwork. Use your own mark, not Salesforce's cloud logo or colors that suggest affiliation.

## Screenshot shot list (1280x800)

Use a scratch org or sandbox with fake data; no real customer names, record data, session ids or API keys in frame. Capture with the real side panel docked next to a Lightning tab (browser window sized so panel plus tab fit 1280x800).

1. **Connected, no setup**: Salesforce Setup tab on the left, side panel on the right with the green org banner (`Org: <myorg>.my.salesforce.com`). Caption: "Uses the Salesforce session you already have. No Connected App."
2. **Describe it**: request typed ("When an Opportunity closes won, create a follow-up Task for the owner") before generating. Caption: "Describe the change in plain language."
3. **Review the result**: generated Flow diagram with the element list. Caption: "Review the Flow before anything touches your org."
4. **Validate and repair**: validation result with an error and the repair action. Caption: "Check-only validation against your org, with one-click repair."
5. **Deployed**: success state with the link to the component in Setup. Caption: "Deploy and jump straight to it in Setup."
Optional 6: **Bring your own key**: provider/model/key settings. Caption: "Your AI key stays in your browser."

Do not show screenshots of features that are still stubbed in the build being submitted (list, retrieve, validate, deploy, agent publish, portal).
